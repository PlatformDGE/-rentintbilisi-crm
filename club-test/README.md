# Тестовая версия клуба Cars Rent in Tbilisi

Собранная копия сайта с модулем клуба для показа партнёрам:
https://platformdge.github.io/-rentintbilisi-crm/club-test/

Не трогает hge.ge. Каталог и фото страница берёт из копии сайта в этом же репозитории (`/-rentintbilisi-crm/site/`, тот же домен, без CORS), логотипы — с hge.ge. Раньше каталог брался с hge.ge/data/, но hge.ge переехал на новый сервер, где этого файла нет и CORS закрыт. Исходники модуля: ветка
`claude/project-thread-dltvnp` (PR #76), `site/club/`. Пересобирается из неё.

## Инвест-калькулятор (только тест)

На карточке объекта на продажу (квартира или дом) под «Об объекте» есть блок «Доходность от сдачи»: долгосрочная аренда и посуточная, годовой доход, % годовых и окупаемость. Это отдельное дополнение к собранной странице, бандл сайта не менялся: `invest/invest.js` и `invest/invest.css` подключены в `index.html`.

Аренда в месяц по умолчанию — медиана по тому же району и числу спален из канала аренды за последний год (`invest/rent-medians.json`, строит `scripts/build_rent_medians.py`; при каждом деплое Pages пересчитывается из свежего `site/data/rent.json`). Если по району и спальням меньше 5 объявлений, берётся оценка по району с поправкой на размер, потом медиана по Тбилиси; для курортов и других городов поле остаётся пустым. Посуточно: $60 за ночь, загрузка 60%, минус 30% расходов. Все поля можно менять.
