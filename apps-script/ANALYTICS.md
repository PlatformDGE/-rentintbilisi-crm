# Своя аналитика сайта hge.ge

Сайт отправляет анонимные события (просмотры, обращения, поиски, ошибки) в отдельную
Google Таблицу. Отчёт — в CRM: **Управление → Аналитика сайта**, только для админов.
Имён, телефонов и cookie нет. Пока адрес скрипта не вписан, счётчик выключен и сайт
работает как раньше.

Код: `apps-script/site-analytics.gs` (сервер), `site/assets/js/analytics.js` (сайт),
`crm-analytics.js` (страница в CRM).

## Установка (один раз, ~10 минут)

1. **Скрипт.** script.google.com → Новый проект (или Расширения → Apps Script в любой
   таблице). Удалите всё в редакторе и вставьте содержимое `site-analytics.gs`. Сохраните.
2. **Таблица** создастся сама при запуске `setup` (шаг 4) — «HGE Analytics» в вашем Google Диске.
3. **Свойства скрипта.** Настройки проекта (шестерёнка) → Свойства скрипта → добавить:
   - `SESSION_SECRET` — скопируйте значение из проекта **CRM Auth** (там же, в свойствах).
     Без него отчёт не узнает вход в CRM. Никому его не пересылайте.
   - `ADMINS` — кто видит отчёт: Telegram ID или username через запятую, например
     `6577307207,6014886676,114756692,davidtibelashvili,kvirkvel1a`.
   - необязательно `RETENTION_DAYS` — сколько дней хранить события (по умолчанию 400).
4. **Первый запуск.** Вверху выберите функцию `setup` → Выполнить → разрешите доступ.
   Появится таблица «HGE Analytics» с листом `Events` (ссылка — в «Журнале выполнения» внизу)
   и расписание: сводка по понедельникам в 10:00 и уборка старых событий.
5. **Опубликовать.** Развернуть → Новое развертывание → тип «Веб-приложение»,
   «Выполнять от имени: меня», «Доступ: все». Скопируйте адрес вида
   `https://script.google.com/macros/s/…/exec` и пришлите его Claude — это не секрет,
   он будет виден в коде сайта. Claude впишет его в сайт и в CRM.

## Еженедельная сводка в Telegram (необязательно)

1. В @BotFather создайте отдельного бота (`/newbot`), например `hge_stats_bot`.
2. Каждый, кто должен получать сводку, открывает бота и жмёт **Start**.
3. В свойства скрипта добавьте `BOT_TOKEN` (ключ бота — только сюда, не в чат и не в код)
   и `REPORT_CHAT_IDS` — Telegram ID получателей через запятую.
4. Проверка: выберите функцию `weeklySummary` → Выполнить.

## Если поменяли код скрипта

Развернуть → Управление развертываниями → карандаш → Версия: «Новая версия» → Развернуть.
Адрес при этом не меняется.

## Что видно в отчёте

Посетители и новые, просмотры объектов, обращения (звонок, WhatsApp, Telegram, офис) и
конверсия; по дням; откуда пришли; какие публикации и ссылки «Поделиться» сработали;
объекты с обращениями и объекты, которые смотрят, но по ним не пишут; агенты; что искали
и не нашли; чем делятся; переходы в соцсети; устройства и языки; скорость сайта; ошибки
у посетителей. Внизу — конструктор ссылок с меткой для постов и Reels.

Ограничения: страну и город посетителя этот способ не показывает. Бесплатных лимитов
Google хватает примерно на несколько тысяч посещений в день.
