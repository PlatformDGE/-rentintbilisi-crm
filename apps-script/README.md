# Вход агентов в веб-CRM через Telegram

Агент открывает CRM на сайте и жмёт «Войти через Telegram». Если его Telegram есть
в листе «Агенты» или «Рекруты» (куда админ добавляет людей через админ-панель CRM),
он входит. Первый вход = регистрация: телефон и дата рождения сохраняются в лист
`Agent_Accounts` (создаётся сам) по Telegram ID. Убрали человека из таблицы или
выключили — при следующем открытии CRM его выкинет.

@real_estating_bot не используется и не меняется. Основной Apps Script CRM тоже не меняется.

## Что сделать один раз

1. **Технический бот для кнопки входа.** В @BotFather: `/newbot` (например `homesingeorgia_login_bot`),
   затем `/setdomain` → выбрать этого бота → `platformdge.github.io`.
   Бот никому не пишет, он нужен Telegram только чтобы показать кнопку входа.
2. **Apps Script.** script.google.com → Новый проект «CRM Auth» → вставить `crm-auth.gs`.
   Настройки проекта → Свойства скрипта:
   - `LOGIN_BOT_TOKEN` — токен бота из шага 1;
   - `SESSION_SECRET` — любая длинная случайная строка (40+ символов).
3. **Развернуть** → Новое развертывание → Веб-приложение, «Выполнять от имени: меня», «Доступ: все».
   Разрешить доступ к таблице.
4. В `index.html` вписать:
   ```js
   var CRM_AUTH_URL = 'https://script.google.com/macros/s/.../exec';
   var TG_LOGIN_BOT = 'homesingeorgia_login_bot';
   ```
   Пока они пустые, кнопка не показывается и CRM работает как раньше.

## Колонки в листах Агенты / Рекруты

Скрипт ищет колонки по заголовку первой строки: Telegram (`telegram`, `tg`, `телеграм`),
имя (`name`, `имя`), активность (`active`, `is_active`, `актив…`; `FALSE`/`нет`/`0` = выключен),
уровень (`level`, `уров…`). Сверка идёт по username без `@` и без учёта регистра.
